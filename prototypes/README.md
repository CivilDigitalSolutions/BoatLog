# Prototypes

Throwaway UI prototypes used to pressure-test a specification before any product
code is written. Nothing in this directory is part of the published BoatLog site:
it is not linked from any page, not in `sitemap.xml`, and every prototype carries
`<meta name="robots" content="noindex,nofollow">`.

Each prototype is a single self-contained HTML file with mock data, no build step
and no network calls. Open it directly in a browser.

| Prototype | Pressure-tests |
|---|---|
| `broe2-import-review/` | BROE2 Competition Module spec v0.1, section 5 step 8 — the import diff confirmation screen |
