Boat booking for rowing clubs

One calendar for the whole fleet, on every member's phone.

What it does

  • A club calendar: every booking for every boat, by day or week.
  • No double bookings: a boat that's already booked can't be booked again for the same time.
  • No-shows released: if nobody takes a booked boat out, the booking is released after a set time (30 minutes by default) so someone else can use it.
  • Fair limits: the club decides how far ahead members can book, so nobody blocks a boat for the season.
  • Restricted boats: private or captain-only boats can be limited to named members.

See it in action

Bookings work alongside sign-out, so a booked boat is ready when its crew arrives, and alongside damage reporting, so nobody books a boat that's out of service.

Questions

FAQ

Can members book boats from their phone?

Yes. BoatLog runs in the phone's browser and can be installed like an app.

What happens if someone books a boat and doesn't turn up?

The booking is released automatically after a set time, 30 minutes by default, so the boat is free for others.

Can we stop people booking boats months ahead?

Yes. The club sets how far ahead members can book.
